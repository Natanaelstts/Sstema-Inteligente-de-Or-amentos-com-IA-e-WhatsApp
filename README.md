# 🤖 Sistema de Orçamentos Inteligente com IA (Omnichannel)

Este projeto é um ecossistema completo de automação de vendas. Ele captura leads, processa dados com Inteligência Artificial e entrega orçamentos personalizados de forma simultânea via WhatsApp e E-mail.
