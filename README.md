# Sstema-Inteligente-de-Or-amentos-com-IA-e-WhatsApp
Desenvolvi um ecossistema de vendas que automatiza o atendimento inicial de hardware. O cliente preenche um formulário, os dados são processados por uma IA (Groq) no n8n, a planilha de estoque é consultada e um orçamento personalizado é enviado via WhatsApp e E-mail.
